# Wildmon 3D — Beta 0.1

Protótipo original de aventura 3D com exploração em terceira pessoa e captura de criaturas.

## O que já está nesta beta
- Cenário 3D low-poly simples, pensado para dispositivos Android.
- Personagem controlável por botões de toque.
- Câmera em terceira pessoa.
- Criatura original chamada **Brasafofo**.
- Mecânica inicial de captura por proximidade.
- Exportação automática de APK pelo GitHub Actions.

## Como gerar o APK
1. Abra a aba **Actions** deste repositório.
2. Selecione **Build Wildmon 3D Android APK**.
3. Abra a execução mais recente e aguarde ficar verde.
4. Em **Artifacts**, baixe **Wildmon3D-Beta01-APK**.
5. Extraia o ZIP e instale o APK no Android.

O APK desta beta é de depuração e serve para testes. A assinatura de publicação será configurada separadamente antes de uma versão de lançamento.

## Tecnologia
Godot Engine 4.4.1, GDScript e renderizador Compatibility (OpenGL), visando compatibilidade com celulares Android.

Todos os personagens e elementos deste protótipo são originais.
